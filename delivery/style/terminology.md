# Project 42 terminology

Authoritative. Models will otherwise invent synonyms for settled terms, and a
corpus with four names for one concept is harder to learn from and impossible
to search.

**Use the left column. Never the right.**

| Use | Not |
|---|---|
| large language model, or model | AI, the AI, an AI |
| model deployment | model instance, model endpoint (when you mean the deployment) |
| endpoint | API, the API endpoint URL |
| prompt | query, question, input (when you mean the prompt) |
| context window | memory, token limit |
| token | word, character |
| inference | a call, generation, completion (when you mean the act) |
| provider | vendor, company, lab |
| provider family | model family, brand |
| agent | bot, assistant, copilot |
| tool call | function call, plugin |
| retrieval | RAG, lookup |
| fine-tuning | training, retraining |
| system prompt | instructions, preamble |
| hallucination | mistake, error, lie |
| evaluation | testing, benchmarking (when you mean evaluation) |
| self-hosted | local, on-prem, private (when you mean self-hosted) |
| learner | user, student, customer |
| module | lesson, unit, chapter |
| learning path | course, track, curriculum (when you mean one path) |
| Field Guide | the guide, guides |

## Product names, exactly

- **Azure AI Foundry** for the hosted cloud service
- **Foundry Local** for the on-device product
- **Azure Local Foundry** for the Azure Local product
- **Project 42** never "P42" or "the platform" in learner-facing text

Never shorten a product name on first use in a module.

## Capitalisation

Sentence case for headings. Product names as the vendor writes them. Do not
capitalise a common noun to make it look important.

## Adding a term

A new row is a decision. Record why, and check nothing in the corpus already
uses the rejected form before adding it.
